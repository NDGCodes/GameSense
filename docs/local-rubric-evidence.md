Trivy scanned the final local backend and frontend runtime images for OS and library vulnerabilities. With the existing `ignore-unfixed` policy and the rubric's HIGH/CRITICAL threshold, both images returned zero matching findings; this means the configured gate passed on these image builds, not that every possible vulnerability class or future image build is clean.

The base Compose file retains frontend port 5173 and Grafana port 3000. For this run, a private Compose override mapped frontend to 5183, backend to 18000, PostgreSQL to 15432, Prometheus to 19090, and Grafana to 13000 because another preview already occupied 5173; no existing preview was stopped. The real bundle source remained unchanged and was copied into private task storage for a read-only container mount compatible with the non-root backend user.
